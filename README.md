# AquaDrive — сайт автомойки

Весь сайт находится в `index.html`. Перед публикацией откройте его и найдите внизу блока `siteConfig`:

```js
const siteConfig = {
  businessName: 'Название автомойки',
  whatsapp: '77001234567',
  phoneText: '+7 700 123 45 67',
  instagramUrl: 'https://instagram.com/your.account'
};
```

Номер WhatsApp вводится только цифрами, без плюса и пробелов. Также замените демонстрационные цены, услуги, адрес и тексты на реальные данные бизнеса.
